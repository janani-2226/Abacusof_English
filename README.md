# Abacus of English

One-page site built with React + Vite + Tailwind CSS v4.

## Run
```bash
npm install
npm run dev
```

## Customise
Everything lives in **`src/config.js`**:
- `forms.bookCoach` / `forms.bookCourse` → paste your two Google Form links
- `coach` → name, bio, profile details, stats, highlights
- `site` → email, phone, location

Add the coach photo as `public/coach.jpg` (initials show until then).

## Build
```bash
npm run build   # output in dist/
```
